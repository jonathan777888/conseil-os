# Jonathan Conseil — site public

Publier ce dossier avec GitHub Pages : Settings → Pages → Deploy from a branch → main → /docs.

Les visiteurs consultent les plans à jour via une API publique en lecture seule et contactent Jonathan par courriel. L’espace administrateur existant reste séparé ; seul le compte propriétaire peut enregistrer des modifications.

Aucun identifiant ni secret ne doit être ajouté au site public. Les autres fichiers du dépôt Conseil OS sont conservés.
